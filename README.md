# نظام كِنان لإدارة المدرسة

نظام عربي RTL للمدارس العراقية مبني بـ PHP وSQLite بمرحلة تشغيلية مستقلة تعمل دون إعداد قاعدة بيانات خارجية.

## التشغيل السريع

شغّل `تشغيل_نظام_المدرسة.bat` بنقرة واحدة. سيعرض عنوان الهاتف والكمبيوتر ويعرضه كرابط QR.

يفتح المشغّل صفحة عناوين واتصال ورمز QR، ويشغّل الخادم على `0.0.0.0:8080` ليعمل على نفس شبكة الواي فاي.

الحسابات التجريبية:

| الدور | اسم المستخدم | كلمة المرور |
|---|---|---|
| مدير | `admin` | `123456` |
| معاون | `assistant` | `123456` |
| مدرس | `teacher` | `123456` |
| محاسب | `accountant` | `123456` |
| ولي أمر | `parent` | `123456` |

غيّر كلمات المرور التجريبية قبل الاستخدام الفعلي.

## المتطلبات

- PHP 8.2 أو أحدث مع امتدادات PDO SQLite وSodium.
- المتصفح الحديث على نفس شبكة الواي فاي.

قاعدة البيانات `kinan_school.db` تُنشأ تلقائيًا في مجلد المشروع ولا تستخدم MySQL.

## النسخ الاحتياطية وGoogle Drive

- يمكن للمدير تنزيل نسخة مشفرة بكلمة مرور.
- يمكن استعادة نسخة مشفرة بعد إدخال كلمة المرور الصحيحة.
- تتطلب وحدة Google Drive بيانات OAuth الخاصة بالمشروع (Client ID وClient Secret وRefresh Token) ومعرّف المجلد اختياريًا.
- لا تُحفظ أسرار Google في المستودع، بل في `data/google-drive.json` الذي يستبعده Git.

## المحاسبة والرسوم

- يملك المدير والمعاون والمحاسب الوصول إلى شاشة المحاسبة والرسوم.
- يدعم النظام أنواع الرسوم والفواتير والخصومات وتسجيل دفعات نقدية أو تحويل أو بطاقة.
- يحسب النظام إجمالي الفاتورة والمتبقي ويمنع دفع مبلغ أكبر من الرصيد.
- يدعم تسجيل المصروفات والإشعارات والتقرير المختصر للمقبوضات والمصروفات والرصيد.

## بوابة ولي الأمر والإشعارات

- يربط المدير أو المعاون حساب ولي الأمر بالطالب في بوابة منفصلة.
- يرى ولي الأمر الطلاب المرتبطين بالحضور والغياب والتأخر والدرجات.
- يستطيع المدير والمعاون إرسال إشعارات عامة أو موجهة إلى ولي أمر أو طالب محدد.
- يمكن تعليم الإشعارات كمقروءة من حساب ولي الأمر.

## المناهج والكتب والنماذج والمراسلات

- يدعم الفصل الدراسي العراقي ابتداءً من الروضة وحتى الصف السادس إعدادي.
- يمكن للإدارة ربط المنهج المعتمد بمرحلة وصف ومادة وسنة دراسية مرجعية.
- يدعم رفع الكتب الرسمية والمحاضرات والواجبات والنماذج والملفات الإدارية حتى 25 ميغابايت.
- يدعم المدرسون إضافة واجبات ومحاضرات مسجلة وصفوف مرتبطة بالمواد.
- يدعم تسجيل المراسلات الصادرة والواردة برقم مرجعي وحالة ومرفق إداري.
- تتطابق الدرجات مع الفصل الأول والثاني والامتحانات الشاملة وأنواع التقييم الشهري والتحريري والعملي ونهاية الفصل.

## Word وExcel

- يصدر النظام قوائم الطلبة والدرجات والحضور بصيغة CSV متوافقة مع Microsoft Excel وUTF-8.
- يصدر تقريرًا عربيًا لقائمة الطلبة بصيغة .doc قابلة للفتح والطباعة في Microsoft Word.
- يمكن استيراد الطلبة من CSV مع معاينة جميع الصفوف قبل التأكيد.
- رؤوس الأعمدة المدعومة للاستيراد: الاسم الكامل، رقم الهوية، رقم القيد، الصف، تاريخ الميلاد، الجنس، ولي الأمر، هاتف ولي الأمر، والعنوان.

## كشوف الدرجات والشهادات

- يمكن استخراج كشف درجات لكل طالب حسب الفصل الأول أو الثاني أو الامتحان الشامل.
- يحسب الكشف نسبة كل مادة والمعدل العام والنتيجة النهائية مع عتبة نجاح مرحلية 50%.
- يمكن استخراج شهادة مدرسية قابلة للطباعة بصيغة Word تعرض الطالب والصف والسنة والمعدل والنتيجة.

## الإرشاد التربوي والسلوك

- تملك الإدارة والمدرسون صلاحية فتح حالات الإرشاد وتسجيل الملاحظات السلوكية والجلسات وخطط التحسين.
- تدعم الحالات فئات أكاديمية وسلوكية ونفسية واجتماعية وحضور وأسريّة، مع أولويات وحالات متابعة.
- يمكن تصنيف السلوك إيجابيًا أو سلبيًا أو محايدًا وتوثيق الإجراء المتخذ.
- يمكن إشعار ولي الأمر عند تسجيل ملاحظة تربوية، مع ظهورها في إشعارات بوابة ولي الأمر.
- تدعم خطط التحسين الأهداف والتدخلات والمسؤول وتواريخ البدء والمراجعة وحالة التقدم.

## الدورات الامتحانية والدرجات النهائية

- يمكن للإدارة إعداد جدول امتحانات لكل مرحلة وصف وسنة وفترة ودور ونوع الالتحاق.
- تدعم القوائم الدور الأول والدور الثاني والدور الثالث، مع الانتساب والدرجات اليومية والشهرية ونصف السنة والنهائية.
- يمكن ضبط أوزان اليومي والشهرى ونصف السنة والامتحان النهائي بشرط أن يكون مجموع الأوزان 100%.
- اعتمدت النتيجة من الإدارة والنتيجة النهائية حسب السياسة المختارة ودرجة النجاح المحددة.
- يسجل كل طالب بنوع الالتحاق، والسنة والفترة والدور لمنع خلط نتائج الدورات.

## الأمان والحسابات

- تخزن كلمات المرور بصيغة تجزئة قوية ولا تظهر في واجهات النظام أو سجل التدقيق.
- يقفل الحساب بعد خمس محاولات خاطئة لمدة 15 دقيقة، ويمكن للإدارة فك القفل.
- يتيح التغيير الذاتي لكلمة المرور والتحقق من كلمة المرور الحالية.
- يمكن للإدارة إنشاء الحسابات وتحديد الدور وتعطيلها وتفعيلها.
- يسجل النظام محاولات الدخول والعمليات الحساسة مثل تغيير كلمة المرور وإنشاء الحسابات وفك القفل.
- تستخدم جلسات الدخول معرفًا متجددًا عند النجاح وCookie مع HttpOnly وSameSite.
